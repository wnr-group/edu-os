Completeness is live, not a nightly snapshot. Each student’s checklist is computed on read (required document types − what’s on file), so the moment a document is uploaded or verified the numbers update. The only scheduled job flips verified → expired when a validity date passes. Documents live in a private bucket — every “View” opens a fresh 60-second signed link, visible to admin & principal (and a class teacher for their own students), never a public URL.
