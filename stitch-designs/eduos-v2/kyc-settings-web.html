Requirements apply school-wide. A Required type counts toward every student’s completeness; Optional ones are collected but don’t block. Turning a type Off deactivates it — existing documents are kept, but it drops out of new checklists (types with documents on file are never hard-deleted). Only a type flagged with a validity period sets an expiry date when verified. Per-class rules (e.g. no TC for Nursery) come later; for now mark such types Optional.
